**Title:** Partnerships and collaboration

**Body:**

This issue is the place to start a conversation about working with this project.

What exists today: the TradeMirror Copy Server and MT5 EA are in Phase 1 and tested on demo
accounts only (see `docs/trademirror/quickstart.md`, "Status and limits"). The repository is
source-available under the PolyForm Noncommercial License 1.0.0, so commercial use needs a separate
license.

You might open a comment here if you:

- want to use the project commercially and need to discuss licensing;
- are a broker, prop firm, or tool vendor interested in integration or testing;
- want to contribute in a way that is larger than one pull request (see `CONTRIBUTING.md`; the CLA
  applies to contributions).

Please include who you are, what you want to build or test, and the account types and platforms
involved (hedging or netting, broker, MT5 build). Do not post credentials, account numbers, tokens or
other private data. If you prefer to share something privately, say so in a comment and the maintainer
will reply with a way to do it.

There is no commitment to accept any proposal or to respond within a set time.
